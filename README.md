# Paradise Nursery | e-plantShopping

A React and Redux Toolkit shopping cart for browsing houseplants. The catalog lists plants by category with photos, care descriptions, and prices. The cart shows each plant's unit price, quantity, line total, and the order total. Users can change quantities, delete plants, and continue shopping. Checkout displays a coming-soon message.

## Run locally

```bash
npm ci
npm run preview
```

Open the preview URL shown in the terminal. Vite's default preview port is 4173.

This project builds on the IBM Skills Network e-plantShopping starter.
